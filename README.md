A modern, responsive web-based team workspace inspired by **Jira, ClickUp, and Trello**. Designed and developed to organize projects, team member workloads, and status lifecycles in a unified single-page interface.

---

## 🌟 Key Features

- **📊 Unified Dashboard:** Live metrics tracking Total, Completed, Running, and Pending projects with dual visual charts.
- **📁 Project Management (Full CRUD):** Add, edit, search, filter, and delete projects with technology skills tagging.
- **📋 Interactive Kanban Board:** 3-column workflow (To Do, In Progress, Completed) featuring HTML5 Drag-and-Drop and instant status updates.
- **👥 Team Workload Analytics:** Dynamic matrix calculating project load and completion success rates per collaborator.
- **📈 Visual Analytics:** Chart.js integration visualizing skill competencies across Java, Python, SQL, and Web stacks.
- **🔍 Real-Time Search & Filtering:** Instant multi-field filtering across project names, tech stacks, and team members.
- **🌓 Dark & Light Mode:** Seamless theme toggle with persistent state saved in LocalStorage.
- **💾 100% Client-Side Persistence:** Zero external backend required—all data persists across browser reloads via HTML5 LocalStorage.
- **📱 Fully Responsive:** Adaptive layout optimized for mobile, tablet, and desktop viewports.
